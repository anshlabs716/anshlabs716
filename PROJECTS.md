# Projects

A directory of projects maintained by AnshLabs716.

- [MILES](https://github.com/anshlabs716/miles) — A modern, customizable, privacy-focused Android activity tracker with GPS tracking, real sensor data and a clean UI.
- [MILES Wear OS](https://github.com/anshlabs716/miles-wearos) — A standalone, sensor-accurate, privacy-focused activity tracker for Wear OS, with local-network sync to MILES and no Google Play Services requirement.
- [GeoNav](https://github.com/anshlabs716/GeoNav) — A FOSS, privacy-first Android navigation platform: maps, routing, offline mapping, search and Android integration.
- [Luogo-FOSS](https://github.com/anshlabs716/Luogo-FOSS) — Privacy-first location sharing and device finding for Android: end-to-end encrypted sharing, crowdsourced BLE finding and a self-hostable backend.
- [SysKit](https://github.com/anshlabs716/syskit) — An all-in-one multi-language system toolkit for information, diagnostics, maintenance, networking, storage and utilities, available in C, Bash, Python and Java, with a Linux GTK3 interface, Termux Lite variants and an Android APK.
- [SnowAnsher](https://github.com/anshlabs716/snowansher) — A fast-paced 3D snowboarding browser game: dodge obstacles, hit ramps, collect gifts, unlock sleds and chase high scores.
- [Flappy Ansh](https://github.com/anshlabs716/flappyansh) — A Java-based Flappy Bird clone with custom difficulty, secret skins, power-ups, particle and weather effects.
- [8vert-enhanced](https://github.com/anshlabs716/8vert-enhanced) — An all-in-one conversion, calculation and notes toolkit (a fork of 8vert).
- [neoncore](https://github.com/anshlabs716/N30NC0R3_AI) — A C-based AI chat assistant with a local LLM, web search, ASCII art and text-to-speech (neoncore v3.0).
- [minifetch](https://github.com/anshlabs716/minifetch) — A tiny system information tool — like neofetch, but smaller, simpler and built with Termux in mind.
- [iso-flasher](https://github.com/anshlabs716/iso-flasher) — A fast, lightweight ISO-to-USB flasher written in Rust, with safe raw-device flashing, live progress and no bloat.
- [invoke-bsod](https://github.com/anshlabs716/invoke-bsod) — A PowerShell project for experimenting with Windows crash behaviour (crash testing).
- [deadly-scripts](https://github.com/anshlabs716/deadly-scripts) — A collection of intentionally disruptive scripts for Linux and Windows, written for experimenting with system behaviour.
- [Linux Mint Lite](https://github.com/anshlabs716/linux-mint-lite) — A lightweight Linux Mint XFCE setup with unnecessary applications removed: no bloat, no fluff, just the essentials.
